Python bridge

The ArbDraw Python bridge is a small local server that connects the browser-based editor to VISA instruments and installed waveform adapters. It runs on your computer and listens only on 127.0.0.1 by default.

Download

Open the current Python bridge release and download the asset whose name ends in .whl.

A wheel is a ready-to-install Python package. The py3-none-any part of the filename means the bridge contains platform-independent Python 3 code and works on Windows, macOS, and Linux. Python 3.10 or newer is required.

The .tar.gz asset is the source distribution intended mainly for developers and packaging tools. Most users should choose the .whl file.

Install and start

Open a terminal in the folder containing the downloaded wheel, then run:

python -m pip install ./arbdraw_python_bridge-0.1.0-py3-none-any.whl
arbdraw-bridge

On Windows, py -m pip can be used instead of python -m pip. Leave the terminal open while using an instrument. Press Ctrl+C in that terminal to stop the bridge.

Connect from ArbDraw

  1. Start the bridge and wait for it to report http://127.0.0.1:8876.
  2. In ArbDraw, choose File → Instruments.
  3. Use the default bridge URL, then connect or refresh the instrument list.
  4. Select a VISA resource and use Identify to confirm the connection.
  5. Select an installed adapter before sending a waveform.

VISA backend

The bridge installs PyVISA, but instrument access also requires a VISA implementation. A vendor installation such as NI-VISA normally works without another option. To use the pure-Python backend, install pyvisa-py and select it when starting the bridge:

python -m pip install pyvisa-py
arbdraw-bridge --visa-library @py

Instrument adapters

Adapters add model-specific waveform transfer support and are installed separately in the same Python environment as the bridge. Without an adapter, the bridge can still perform health checks, discover VISA resources, and issue identification or SCPI queries, but it cannot send a waveform.

Troubleshooting

  • Bridge offline: Confirm the terminal is still running and the URL is http://127.0.0.1:8876.
  • No VISA resources: Confirm your vendor VISA software or pyvisa-py is installed and can see the instrument.
  • No waveform adapter: Install a compatible adapter in the same Python environment, then restart the bridge.
  • Command not found: Try python -m python_bridge, or ensure your Python scripts directory is on PATH.

For advanced options, API endpoints, source installation, and adapter development, see the complete Python bridge documentation.
