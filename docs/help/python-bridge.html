Python bridge

The ArbDraw Python bridge is a small local server that connects the browser-based editor to VISA instruments and installed waveform adapters. It runs on your computer and listens only on 127.0.0.1 by default.

Download and install

Open the latest ArbDraw bridge release and download arbdraw-bridge-with-adapters.zip. It contains the bridge plus adapter packages for OWON XDG3000 / Multicomp MP750290, Rigol DG1022, and TekScope MSO2/MSO6 instruments. Python 3.11 or newer is required.

Extract the ZIP and open a terminal in the extracted folder. Install and start the bridge with the same Python interpreter:

python install.py
python -m python_bridge

The installer downloads Python dependencies and verifies that the adapters load. To install only one package, use python install.py --adapter owon-xdg3000, python install.py --adapter rigol-dg1022, or python install.py --adapter tekscope. The TekScope package registers both tekscope-mso2 and tekscope-mso6.

On Windows, pip creates arbdraw-bridge.exe and arbdraw-bridge-tray.exe in that Python environment's Scripts folder. Run the tray app for notification-area Start, Stop, and Restart controls without a console window, or run arbdraw-bridge.exe directly. If you already installed an older bridge wheel, run the ZIP installer using that same Python environment to upgrade the bridge and add adapters.

The tray menu shows the current bridge version and available adapters. Its ArbDraw favicon is grey while the bridge is stopped, starting, stopping, or in an error state, and changes to blue when the health check confirms the bridge is running.

Individual .whl assets are also available for manual installation. Install a chosen adapter wheel with the same interpreter that runs the bridge. The .tar.gz assets are source distributions for developers and packaging tools. Leave the bridge terminal open while using an instrument; press Ctrl+C to stop it.

Use instruments with a local copy

Opening index.html directly as a file:// page still supports waveform editing, saving, and exporting. Instrument discovery, Identify, and Send to AWG require the hosted app or a trusted web origin. Browsers give local files an opaque origin that the bridge cannot distinguish from untrusted pages, so it rejects these requests before running instrument commands.

After installing the bridge and the required adapter, open a terminal in the ArbDraw source folder containing index.html and run:

python -m python_bridge --serve-app .

Open http://127.0.0.1:8876 in your browser. The . means the current source folder, not the extracted bridge installer folder. Keep the terminal running. If a tray/menu-bar bridge is already using port 8876, stop it before starting this command.

Save your current waveform as JSON before switching pages, then reopen it in the served app. Browser preferences are stored separately for different origins.

The hosted ArbDraw app remains supported with python -m python_bridge or the tray/menu-bar launcher; it does not require --serve-app. Other web servers need an explicit trusted --allow-origin with the exact origin and port.

Connect from ArbDraw

  1. Start the bridge and wait for it to report http://127.0.0.1:8876.
  2. Open the hosted app or the local served app described above, then choose File → Send to AWG.
  3. Use the default bridge URL, then connect or refresh the instrument list.
  4. Select a VISA resource and use Identify to confirm the connection.
  5. Choose the matching AWG Profile before opening the dialog. ArbDraw selects its preferred installed backend automatically; verify it before sending.

VISA backend

The bridge installs PyVISA, but instrument access also requires a VISA implementation. A vendor installation such as NI-VISA normally works without another option. To use the pure-Python implementation, install pyvisa-py into the same environment and select it when starting the bridge:

python -m python_bridge --visa-library @py

Instrument adapters

Adapters add model-specific waveform transfer support. The ZIP installs their separate wheels into the bridge's Python environment. Confirm they loaded in the bridge startup output or the backend list in File → Send to AWG after connecting. Without an adapter, the bridge can still discover VISA resources and identify instruments, but it cannot send a waveform.

For supported Tektronix models, installation checks, the ArbDraw send workflow, file behavior, and MSO2/MSO6 limitations, open the TekScope adapter guide.

Troubleshooting

  • Local file cannot connect: A file:// address cannot access instruments. Follow Use instruments with a local copy and reopen the app at http://127.0.0.1:8876.
  • Bridge offline: Confirm the terminal is still running and the URL is http://127.0.0.1:8876.
  • No VISA resources: Confirm your vendor VISA software or pyvisa-py is installed and can see the instrument.
  • No waveform adapter: Run install.py from the release ZIP with the same Python interpreter used to start the bridge, then restart it.
  • Command not found: Try python -m python_bridge, or ensure your Python scripts directory is on PATH.
