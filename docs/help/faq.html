Frequently Asked Questions

Where is my waveform stored?

The current waveform exists in the open browser tab until you save it. Use File → Save JSON Waveform to create an editable project file.

What does the Default button do?

It asks for confirmation, clears saved application settings from local storage, and reloads the application using js/defaults.js.

How do I add noise?

Open Filters, choose Add Noise, enter a percentage, and apply the filter.

Why do I not see the Low-Pass Filter option?

The low-pass filter is experimental and can be exposed with the lpf=1 URL parameter.

What is the difference between the Editor and Waveform views?

The Editor is used to create and edit sample values. The Waveform view is a read-only, oscilloscope-style view for inspecting the resulting signal.

Which browsers are supported?

ArbDraw is intended for current versions of Firefox, Chrome, and Safari.
