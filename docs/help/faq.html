Frequently Asked Questions

Where is my waveform stored?

The active waveform exists in the open browser tab until you save it. Use File → Save JSON Waveform to create an editable project file.

What does the Default button do?

It clears saved application settings from local storage, and reloads the application using js/defaults.js.

How do I add (vertical) noise to a waveform?

Open Filters, choose Add Noise, enter a percentage, and apply the filter.

What is the difference between the Editor and Waveform views?

The Editor is used to create and edit sample values. The Waveform view is a read-only, oscilloscope-style view that lets you change scaling factors. The oscilloscope view also auto-repeats the signal.

Which browsers are supported?

ArbDraw is intended for current versions of Firefox, Chrome, and Safari.
