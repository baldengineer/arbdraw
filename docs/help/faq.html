Frequently Asked Questions

Where is my waveform stored?

The active waveform exists in the open browser tab until you save it. Use File → Save JSON Waveform to create an editable project file.

What does the Default button do?

It clears saved application settings from local storage, and reloads the application using js/defaults.js.

How do I add (vertical) noise to a waveform?

Switch the Editor to Advanced. In Properties, check Add noise and enter the amount as a percentage.

What happens when I switch between Basic and Advanced?

Basic generates a waveform from its waveshape and Properties. Advanced also lets you edit points and apply noise or smoothing filters. Switching to Advanced keeps the waveform. If you have made point edits or enabled filters, switching back to Basic asks you to confirm. Cancel keeps your Advanced work; continuing discards it, regenerates the waveform from its current Properties, and clears the earlier edit history. Without Advanced edits or active filters, the switch needs no confirmation. See How to use ArbDraw for details.

What is the difference between the Editor and Waveform views?

The Editor is used to create and edit sample values. The Waveform view is a read-only, oscilloscope-style view that lets you change scaling factors. The oscilloscope view also auto-repeats the signal.

Which browsers are supported?

ArbDraw is intended for current versions of Firefox, Chrome, and Safari.
