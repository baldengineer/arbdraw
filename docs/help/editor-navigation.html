Scrolling and zooming in the Editor

The Editor can show the entire waveform record or a smaller range of samples. Panning and zooming change only which points are visible—they do not remove or resample waveform data. Point numbers and cursor readouts always refer to positions in the complete memory record.

Full-record navigator

The narrow waveform below the main editor represents the complete memory record. Its highlighted window shows the portion currently visible in the editor.

  • Drag the highlighted window to pan through the record.
  • Click elsewhere in the navigator to center the visible window at that point.
  • When the highlighted window fills the navigator, the editor is showing the full record.

Points and Position controls

  • Points / Screen is the number of waveform samples visible at once. The minus button halves the value to zoom in. The plus button doubles it to zoom out. You can also enter an exact value.
  • Position is the sample index at the center of the editor. Its arrow buttons move by approximately 10% of the visible points.
  • Full Record zooms out to show every sample.

Mouse wheel

Pointer locationActionResult
Waveform or Position fieldWheelPan one point per wheel step.
Waveform or Position fieldShift + wheelPan by approximately 10% of Points / Screen. For example, 512 visible points move 51 points per step.
WaveformAlt + wheel upHalve Points / Screen and zoom in.
WaveformAlt + wheel downDouble Points / Screen and zoom out.

Wheel up moves toward later points; wheel down moves toward earlier points. Zooming keeps the current Position centered whenever the record boundaries allow it.

Keyboard shortcuts

ShortcutResult
HomePan to the beginning of the record.
EndPan to the end of the record.
Shift + HomeCenter the visible window on the record midpoint.
Shift + EndCenter the visible window on the record midpoint.

When the highlighted navigator window has keyboard focus, the arrow keys pan by one point. Hold Shift with an arrow key to pan by half of the visible points.
