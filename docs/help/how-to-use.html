How to Use ArbDraw

Open the editor

You can open index.html directly to edit, save, and export waveforms. To use instrument discovery, Identify, or Send to AWG with a local copy, install the Python bridge and required adapter, then run python -m python_bridge --serve-app . from the ArbDraw folder containing index.html. Open http://127.0.0.1:8876 instead of the file page. The hosted app remains supported. See Python bridge setup for details.

Create a waveform

  1. Choose a waveshape from the Waveshape selector.
  2. Note: The amplitude settings set the visual scale. The values are saved in the JSON file. However, the exported waveform does not contain absolute voltage points.
  3. Use the Waveform view to inspect the generated signal with oscilloscope-style controls.

Basic and Advanced editing

Use the Basic and Advanced buttons above the Editor waveform to choose how you work with the waveform. A new project starts in Basic.

  • Basic: Choose a waveshape and adjust its Properties to generate the waveform. The Samples view shows the point values, but they are read only. Point editing tools and filters are unavailable.
  • Advanced: Select or draw points in the Editor, edit values in the Samples view, and use the Add noise or Smoothing checkboxes in Properties. Checking a filter enables its value field.

Switching from Basic to Advanced keeps the current waveform. If you have edited points or enabled a filter, switching back to Basic opens a confirmation dialog. Cancel keeps the Advanced waveform. Switch to Basic discards the point edits and filters, regenerates the entire waveform from its current waveshape and Properties, and clears the previous edit history. If there are no Advanced edits or active filters, switching to Basic does not need confirmation.

Projects saved with point edits or active filters open in Advanced so their waveform can be inspected and edited. A new project opens in Basic.

Create a Math waveform

Choose Math from Waveshape. Enter an expression or choose a preset, then select Apply expression or press Ctrl/Command+Enter. Presets fill the draft without applying it. Escape restores the applied expression.

x runs from 0 up to (but not including) 1 per cycle, shifted by Phase. Try sin(2*pi*x), exp(-4*x)*sin(8*pi*x), or 2*exp(-80*(x-0.5)^2)-1. Results are clipped to −1…1, then scaled by Amplitude and Offset; filters run afterward. Cycles and Frequency control repetition and timing. Each segment retains its own expression. An active Arbitrary selection receives the complete cycle span without changing points outside it.

Use explicit multiplication (2*x), ^ for powers, and radians for angles. Constants are pi and e. Functions: sin, cos, tan, abs, sqrt, exp, log (natural), floor, ceil, round, sign, and two-argument min, max, pow. JavaScript is not supported. Errors leave samples unchanged. Validation checks sampled positions; there is no automatic antialiasing. Expressions are saved with the project and support undo/redo.

Create serial data

  1. Select Serial as the waveshape.
  2. Choose the protocol and configure baud rate, word size, bit order, parity, and idle bits.
  3. Enter a text or hexadecimal payload.
  4. ArbDraw recalculates the waveform timing from the serial sequence and baud.

Save and export

Use File → Save JSON Waveform to save an editable project file. Use File → Export Waveform to export CSV data, with or without metadata headers.

Reset settings

The Default button in the Properties panel restores the application settings defined in js/defaults.js. The action asks for confirmation before clearing saved browser settings.
