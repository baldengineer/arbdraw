How to Use ArbDraw

Create a waveform

  1. Choose a waveshape from the Waveshape selector.
  2. Set the high and low voltage levels, frequency, phase, duty cycle, and sample settings in the Properties panel.
  3. Use the Editor view to inspect or edit the waveform.
  4. Use the Waveform view to inspect the generated signal with oscilloscope-style controls.

Use serial data

  1. Select Serial as the waveshape.
  2. Choose the protocol and configure baud rate, word size, bit order, parity, and idle bits.
  3. Enter a text or hexadecimal payload.
  4. ArbDraw recalculates the waveform timing from the serial sequence.

Save and export

Use File → Save JSON Waveform to save an editable project file. Use File → Export Waveform to export CSV data, with or without metadata headers.

Reset settings

The Default button in the Properties panel restores the application settings defined in js/defaults.js. The action asks for confirmation before clearing saved browser settings.
