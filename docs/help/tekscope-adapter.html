TekScope adapter

The TekScope adapter sends the current ArbDraw waveform to the built-in AFG on supported Tektronix MSO2 and MSO6 scopes. It transfers a Tek waveform CSV to the scope, selects that file as the arbitrary source, and applies frequency, amplitude, offset, load, and output state.

Supported backends

ArbDraw profileBridge backendAccepted models
TekScope MSO2 (files)tekscope-mso2MSO22, MSO24, MSO22-EDU, MSO24-EDU
TekScope MSO6 (files)tekscope-mso6MSO64, MSO66, MSO68, and their B variants

The scope must have its AFG capability available, be reachable from the bridge computer, and be visible through a VISA implementation such as NI-VISA. The adapter currently writes into C:/baldee; create that folder on the scope before the first transfer.

Install the bridge and adapter

  1. Install Python 3.11 or newer and a VISA implementation.
  2. Download and extract arbdraw-bridge-with-adapters.zip from the latest ArbDraw release.
  3. Open a terminal in the extracted folder and install only the shared TekScope package, or omit --adapter tekscope to install every bundled adapter.
python install.py --adapter tekscope

One TekScope package registers both model-specific bridge backends. Always use the same Python interpreter to install and start the bridge.

Verify VISA before starting ArbDraw

python -m python_bridge --list-resources
python -m python_bridge --idn 192.168.128.233

A bare IPv4 address is accepted and becomes a VXI-11 resource such as TCPIP0::192.168.128.233::INSTR. Replace the example address with your scope's address. Then start the bridge and leave the terminal open:

python -m python_bridge

Send a waveform from ArbDraw

  1. Select TekScope MSO2 (files) or TekScope MSO6 (files) in AWG Profile.
  2. Create the waveform and choose its sample count, frequency, and voltage levels.
  3. Choose File → Send to AWG and connect to http://127.0.0.1:8876.
  4. Select a discovered VISA resource, or enter the scope's IP address directly.
  5. Select Identify (*IDN?) and confirm the returned model matches the chosen profile.
  6. Confirm the waveform backend automatically selected tekscope-mso2 or tekscope-mso6.
  7. Channel is automatically set to 1 and disabled for both TekScope backends. Select Enable output only when the AFG should turn on after a successful transfer.
  8. Confirm Path (initially C:/baldee/) and select Overwrite waveform file to replace an existing file. Both preferences are saved in local browser settings.
  9. Select Send waveform and wait for the verified success message.

The destination filename is derived from the ArbDraw project name. With Overwrite waveform file off (the default), an existing destination causes an error asking you to change the project name or enable overwrite. With overwrite selected, the adapter disables AFG output, deletes the existing destination, and writes the new file. It reads the file back, selects it, applies the requested settings, and only then restores output to the requested state. Replacement is not atomic: if writing fails after deletion, the previous file is no longer available.

MSO2 transfer limit

Tested MSO2 firmware rejects a FILESystem:WRITEFile payload near 8,092 bytes. The adapter conservatively rejects encoded files of 8,000 bytes or more before changing AFG state. This is a firmware file-transfer issue, not the scope's advertised waveform-memory depth. A 100-point waveform is known to work; larger records can exceed the byte limit even when their point count is valid.

MSO6 hardware validation

The MSO6 backend does not inherit the MSO2 byte limit. Its arbitrary-waveform profile supports up to 131,072 points at a maximum 250 MS/s, with a 0.1 Hz to 25 MHz repetition-rate range subject to the sample-rate limit. End-to-end ArbDraw transfers have been verified on MSO6 hardware through 100,000 points, including upload, readback verification, arbitrary-source selection, and AFG configuration. The exact model, firmware revision, VISA implementation, and transport framing details have not yet been recorded.

Troubleshooting

  • Bridge offline: Keep python -m python_bridge running and use the default loopback URL.
  • No TekScope backend: Run python install.py --adapter tekscope with the same interpreter that starts the bridge, then restart it.
  • No VISA resource: Check the scope's LAN settings, ping its address, and verify NI-VISA or your chosen VISA implementation can see it. You can still type a bare IP address into ArbDraw.
  • Unsupported instrument: Match the MSO2/MSO6 profile and backend to the model returned by *IDN?.
  • Scope path error: Confirm C:/baldee exists on the scope.
  • MSO2 instrument limit exceeded: Reduce the sample count; increasing the timeout does not bypass the firmware's block-size failure.
