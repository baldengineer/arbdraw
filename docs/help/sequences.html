Sequences

A sequence joins multiple waveform segments into one memory record. Each segment has its own waveshape, voltage levels, timing, filters, and samples. Use it to combine pulses, steady levels, serial data, and other waveshapes in a single output.

Create a sequence

  1. Choose the AWG profile and prepare the first waveform.
  2. Select Add Segments beside Full Record. ArbDraw switches to Arbitrary mode and creates two segments: the existing waveform and a copy.
  3. Select a segment card above the full-record overview to edit that segment.
  4. Select the + card at the right to append another segment. It copies the selected segment's properties and samples. When the full sequence is displayed, it copies the last segment.

The AWG profile stays fixed while the sequence exists. Its sample limit applies to the combined record. If another segment would exceed that limit, reduce the sample count of an existing segment before adding it.

Edit a segment or inspect the full record

Each card shows a waveform preview and an editable sample count. Select the card to show that segment in the main editor. Properties, filters, drawing tools, point-selection markers, and edits in the Samples view apply to that segment. Its point indices start at zero, and its voltage axis fits its own levels.

Click the full-record overview below the cards, or select Full Record, to display all segments in order. This view is read only. Select a segment card to resume editing. The highlighted portion of the overview identifies the selected segment; in full-record view it follows the visible range as you zoom and pan.

The oscilloscope-style Viewer, browser playback, and Send to AWG use the complete sequence even when one segment is selected in the editor.

Segment timing and sequence timing

All segments use one shared sample clock. When you first add segments, ArbDraw establishes that clock from the existing waveform's sample count and output period, preserving the original waveform's output timing.

Control or readoutMeaning
Frequency / Period in PropertiesThe selected segment's source frequency and period.
N CyclesThe number of source cycles in the selected segment.
Sample count on a cardThe length of that segment in points.
Sample rateThe shared clock for the entire sequence.
AWG Frequency / AWG PeriodHow often the complete sequence repeats, and the duration of one complete record.

Changing a segment's sample count changes its duration and source frequency. Changing its source frequency, period, or cycle count adjusts its sample count at the shared clock. Timing is rounded to whole samples and constrained by the AWG profile's remaining record capacity.

For example, a 2,000-point segment containing one 1 kHz cycle establishes a 2 million samples/second clock. Two copies make a 4,000-point sequence lasting 2 ms, so the AWG repeats the full record at 500 Hz. If the second segment is reduced to 1,000 points, its source frequency becomes 2 kHz and the complete sequence lasts 1.5 ms.

For a serial segment, baud rate controls bit timing. Configure its payload, framing, and idle bits in Serial properties. Serial samples use the shared clock, so bit edges are limited to that clock's sample resolution and the available record capacity.

Export the record or a segment

Open File → Export Waveform and choose the scope before selecting CSV, SVG, or WAV:

  • Full Record exports every segment in sequence order.
  • Segment X exports only the selected segment, where X is its card number. This choice is available only while a segment is selected.

The export dialog shows the chosen scope and sample count. Segment exports start their time axis at zero and retain the shared sample rate. Their default filenames include the segment number, and updating the project name is unchecked by default. WAV export requires a supported sample rate between 8 and 384 kHz.

Save, undo, and remove segments

Use File → Save JSON Waveform to keep the complete editable project, including every segment's source settings and samples. Opening the project restores the sequence in Arbitrary mode and displays the full record. The selected card and editor zoom are not saved.

Undo and redo include segment additions, removals, property changes, and point edits. Select × on a card to remove that segment. When only one segment remains, ArbDraw returns to a single waveform.

Switching to Basic asks for confirmation before discarding the sequence. It keeps the selected segment, or the first segment when viewing the full record, and regenerates that waveform from its source properties and current filters. This conversion clears the previous edit history. Save a JSON project first if you want to retain the sequence.
