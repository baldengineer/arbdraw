About ArbDraw

ArbDraw is a browser-based waveform editor for creating, viewing, editing, and exporting arbitrary waveforms.

What it can do

  • Create common waveform functions and serial data waveforms.
  • Edit custom waveforms directly in the editor.
  • Apply waveform filters (currently just noise)
  • Save and restore projects (via JSON)
  • Export waveform data as CSV.

ArbDraw runs locally in a modern web browser. Your saved settings can be retained in the browser using local storage.
