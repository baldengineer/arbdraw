ArbDraw Workflow

ArbDraw follows a simple three-step process: draw the waveform, transfer the data, and configure the AWG to generate it.

1. Draw

Create the waveform you need in the editor.

  • Edit individual waveform points in the Editor view.
  • Choose a waveshape such as sine, square, triangle, or DC and configure its properties.
  • Add noise or other processing with the Filters menu.
  • Select Serial to generate a UART stream from a text or hexadecimal payload.

Use the AWG controls to choose the instrument profile and define the sample rate, sample count, and timestamp resolution. The AWG Frequency and AWG Period fields show the timing settings to use on the instrument.

2. Transfer

Move the generated waveform data to your test equipment using one of these methods:

  • Download a CSV file and load it with the AWG's software or storage workflow.
  • Use the Python bridge to transfer the waveform directly to supported AWG models and adapters.

Choose the transfer method that matches your AWG and connection. The CSV contains the waveform points; the instrument timing and voltage settings are configured in the next step.

3. Generate

Configure the AWG to reproduce the waveform:

  1. Load the pattern if the instrument requires a separate load or recall operation.
  2. Set the AWG Frequency to the value shown in ArbDraw's AWG Frequency field, or set the AWG Period to the value shown in AWG Period.
  3. Set the output voltage, amplitude, offset, and output state as desired.

For a single-cycle waveform, the timing controls and AWG settings correspond directly. When the waveform contains multiple cycles, use the AWG Frequency or AWG Period shown for one cycle so the generated waveform has the intended timing.
